# QR-Code-Generator — QRify
A Sleek, Privacy-friendly Web App that turns any Text or Link into a Downloadable QR Code (PNG or SVG). Single File with No Backend, Deployed with GitHub Actions + Pages.

- Generate QR Codes from any Text, URL or Wi-Fi Details
- Choose Size, Error Correction and Colors
- Download as PNG or SVG, or Copy the Image
- Runs fully in the Browser, so your text is Never Uploaded
- Auto-deployed to GitHub Pages with a CI/CD Pipeline

## Run Locally or View Online

### Run locally
Open `index.html` in any Browser.
